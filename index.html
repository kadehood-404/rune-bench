What is Rune Bench?

Rune Bench is a free, open-source-style online workbench for developers, CTF players, reverse engineers and security researchers. Paste data, stack transforms into a recipe, and watch every intermediate step. It runs entirely in your browser — no uploads, no accounts, no logging.

Base64 decode & encode online

Standard and URL-safe Base64, with automatic padding repair. Chain it with gunzip, JSON pretty-print or hex.

JWT decoder

Split a JSON Web Token into header, payload and signature. Decoding only — it does not verify signatures.

XOR brute force (single-byte)

Try all 256 one-byte keys and rank results by how English-like they look. Handy for CTF challenges and malware strings.

MD5, SHA-1, SHA-256, SHA-512 & HMAC generator

Hash text locally with WebCrypto, plus a pure-JS MD5. MD5 and SHA-1 are for checksums and forensics, not security.

AES-256-GCM encrypt & decrypt

Passphrase-based encryption using PBKDF2-SHA256 (100k iterations) and a random salt and IV, all through the browser's native crypto.

Regex tester & replacer

Find matches with capture groups or run find-and-replace with $1 backreferences, as a step in any recipe.

Hex, binary & URL decoding

Convert hex, binary, URL-encoding, HTML entities and \uXXXX escapes back to readable text.

IOC extraction & defanging

Pull URLs, IPv4 addresses, emails and hashes out of messy logs, and defang or refang indicators for safe sharing.

Is my data safe?

Everything is computed in your browser. Shareable links store your recipe and input in the URL fragment (after the #), which browsers never send to a server — but anyone you give the link to can read it, so don't share links containing secrets.

Runs 100% client-side. View source — it's one file, no trackers, no bullshit. AES uses WebCrypto (PBKDF2-SHA256 100k → AES-256-GCM); MD5/SHA-1 are for forensics, not for protecting anything.
